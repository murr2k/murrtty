murrtty

A native Windows terminal, forked from Ghostty.

murrtty is Ghostty's core (terminal emulation, fonts, rendering, configuration) with a Win32 application around it, built directly on the Windows API. It looks like Ghostty's GTK app, reads Ghostty's configuration format, and goes its own way where Windows or its own features call for it.

What it does

  • Tabs and splits, GTK's header bar as the title bar, its menus, dialogs and command palette.
  • Shell integration for PowerShell 7, Windows PowerShell 5.1 and cmd (with Clink): the working directory follows the shell, idle prompts close without asking, jump between prompts.
  • Keys reach console programs whole, as Windows key events; keyboard layouts and input methods.
  • Session restore: windows, tabs, splits and each terminal's command history come back, however murrtty was closed.
  • A bell in the header bar for each terminal waiting for you in the background (an agent asking for input, say): a click goes there.
  • Notifications, taskbar progress, global key bindings, the tray, a quick terminal, drag and drop, undo of closes, the terminal inspector.
  • A configuration editor that edits your Ghostty-format file in place, with undo and a review of each change before it saves.
  • A selection that always shows and text that reads, whatever the theme or background color you choose.
  • Screen readers read its terminals through UI Automation.
  • Updates, off until you turn them on: checks, and for copies the installer installed, downloads checked against murrtty's signature that install themselves. What a check sends is below.

Get it

Build from source (recommended): one command; the builder fetches the Zig compiler it needs, and neither Visual Studio nor the Windows SDK is needed. 

git clone https://github.com/murr2k/murrtty
cd murrtty
.\build-windows.cmd

That builds the newest development version, ahead of the release below (it names itself after the branch and commit, as in -main+1a2b3c4d5). To build release @RELEASE@ instead, run git checkout murrtty-v@RELEASE@ before .\build-windows.cmd. Behind a proxy the Zig compiler can't use, .\build-windows.cmd -Deps release downloads the dependencies as one zip, with Windows' proxy settings.

Or install murrtty @RELEASE@, a preview tested on one machine so far (how it is tested); its release notes list the known risks. The installer (x64, ARM64) installs it for you alone, no administrator needed, with a Start menu shortcut and Open in murrtty on folders; or download the zip (x64) and run it from any folder. Neither is code signed, so Windows SmartScreen warns before running it the first time; the code signing policy says what comes after.

Or with Scoop:

scoop bucket add murrtty https://github.com/murr2k/scoop-murrtty
scoop install murrtty/murrtty

It needs Windows 10 (1809 or newer) or Windows 11 on x64 (an ARM64 build is out too, so far tested only on GitHub's ARM64 runners, which have no GPU). It draws with Direct3D 11; without a graphics driver for it, it draws with Windows' own software renderer, slower but the same. The README says what is tested, what isn't, and what isn't built yet.

Privacy

murrtty makes no network connections of its own unless you check for updates or turn automatic checks on, which asks first. A check sends one request to murrtty.org, with no version, ID or cookie. Cloudflare, which serves murrtty.org, sees your IP address, as for any website. murrtty.org neither logs nor counts checks. Downloads come from GitHub, only when you choose one or turn on automatic downloads, and run only once they match murrtty's signature. Crash reports stay on your computer.
