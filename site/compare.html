Windows terminals built from Ghostty

Ghostty has no Windows app, and its maintainers point those who want one to Ghostty's VT library or to forking the project. Several people have done one or the other. This page lists the projects we know of as of 31 October 2026: what each is built on, what it does and how it ships. It is written by murrtty's author, so weigh it with that in mind. Each project here is someone's work, given away; if anything below is wrong or out of date, please say so and it will be fixed.

Which one suits what

  • Ghostty's own app and config file on Windows, current with Ghostty's releases: murrtty.
  • A polished WinUI interface, signed builds and updates, if you sponsor: Wintty.
  • Installing from winget, Scoop or Chocolatey today, shell profiles, ARM64: noctty.
  • A WinUI 3 window over Ghostty's config: GhosttyWin32.
  • Direct3D rendering in a Win32 port that follows Ghostty closely: Gooztty.
  • Supervising several AI coding agents side by side: Polter.
  • WSL only, with a real Linux terminal behind it: ghostinthewsl.
  • Lua scripting and workspaces, WezTerm style: hollow.
  • A light single-window terminal for Windows and macOS: Mostty.
